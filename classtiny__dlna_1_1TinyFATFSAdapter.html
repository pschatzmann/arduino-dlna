Detailed Description

Makes a TinyFATFS volume usable with SdFatContentProvider.

SdFatContentProvider builds its directory tree from the recursive listing provided by SdFat's ls(). This adapter provides the same chdir()/ls() API for a TinyFATFS volume (fatfs::SDClass) with any of its drivers (SPI, SDMMC, RAM, ...). It is available on all platforms supported by TinyFATFS.

The listing uses the FatFs directory functions (f_opendir/f_readdir), which provide the name and the directory flag of each entry without opening it.

Usage:

#include "fatfs.h"
#include "tools/TinyFATFSAdapter.h"
fatfs::SDClass sd;
TinyFATFSAdapter fs_adapter(sd);
SdFatContentProvider<TinyFATFSAdapter> contentProvider;
...
sd.begin(CS, SPI);
contentProvider.begin(fs_adapter, "/");
...
fatfs::File file = fs_adapter.open(node.path().c_str());
