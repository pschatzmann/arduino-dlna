Detailed Description

Print decorator which collects small writes into a buffer.

Network clients send each write() as a separate TCP packet when Nagle's algorithm is disabled: writing an XML document character by character (e.g. via EscapingPrint) is then extremely slow. This class forwards the data in blocks of the indicated size. Call flush() at the end to send the rest.

write() always reports the logical number of bytes, so that the caller can compare it with a precalculated Content-Length. If the destination fails to accept the data (e.g. the client closed the connection), all further data is dropped: check hasError().
