Detailed Description

Parser for a HTTP "Range" request header (RFC 7233)

Supports a single byte range in the forms "bytes=first-last", "bytes=first-" and "bytes=-suffixLength". Multiple ranges (separated by ",") and other units are not supported: parse() returns false and the request should be answered with the full content (200), which is permitted by the RFC.

Usage:

HttpRange range;
if (range.parse(client.requestHeader().get("Range"), file.size())) {
if (!range.isSatisfiable()) {
client.replyRangeNotSatisfiable(file.size());
} else {
file.seek(range.start());
client.replyRange(mime, file, file.size(), range.start(), range.end());
}
} else {
client.reply(mime, file, file.size());
}
